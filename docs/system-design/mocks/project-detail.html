Sodium

Sodium is a powerful rendering engine for Minecraft which improves frame rates and reduces micro-stutter, while fixing many graphical issues.

  • Up to 2–3x faster rendering on most hardware
  • Improved chunk loading and culling
  • Works with shader packs through Iris
