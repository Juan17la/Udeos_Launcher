Udeos Launcher is a small program to install and play Minecraft on Windows,
macOS and Linux. **You do not need a Microsoft account.** Pick a name, pick a
version, press Play.

This is a small fix on top of
[1.2 Beta](https://github.com/Juan17la/Udeos_Launcher/releases/tag/v1.2.0-beta).
If something breaks, please
[open an issue](https://github.com/Juan17la/Udeos_Launcher/issues) and say
what you did.

## Fixes

- **Windows: updating from the launcher works.** Update found the new
  version but stopped with "The requested operation requires elevation".
  Now Windows asks for permission and the installer runs.

## Updating on Windows

Your current launcher still has this bug, so **Update** will fail once more.
Download the Windows installer from the table below and run it. It installs
over your current launcher and keeps your instances, profiles and skins.
From this version on, **Update** works on its own.

## Good to know

- **Online servers.** Servers that check for a Microsoft account will not let
  you in. Single player works, and so do servers set to "offline mode".
- **The installers are not signed yet.** Windows and macOS show a warning the
  first time you open the launcher. The table below says how to get past it.
