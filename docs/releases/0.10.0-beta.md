Udeos Launcher is a small program to install and play Minecraft on Windows,
macOS and Linux. **You do not need a Microsoft account.** Pick a name, pick a
version, press Play.

This is the first beta. It has everything below and it works, but it is
still young: if something breaks, please
[open an issue](https://github.com/Juan17la/Udeos_Launcher/issues) and say
what you did.

## What you can do

**Play without an account.** Type a nickname and you are in. You can save
several nicknames and switch between them from the menu in the top bar.

**Create instances.** An instance is one copy of Minecraft with its own
version, mods and worlds. Make as many as you want; they never mix. Give each
one a name and an icon (real Minecraft blocks and items).

**Pick your version and loader.** Plain Minecraft, or Fabric, Forge, NeoForge
or Quilt. The launcher installs the loader for you the first time you press
Play. There is nothing to download or run by hand.

**No Java to install.** The launcher fetches the Java that each Minecraft
version needs, on its own, the first time you play.

**Add mods, resource packs and shaders.** The Addons page searches Modrinth.
Pick something, press Add, choose the instance, done. The launcher checks
that it fits your version and loader, and brings along anything the mod
needs to run.

**Modpacks.** Add a modpack and the launcher builds a new instance from it,
with the right version, loader and mods. You can also pour a pack's mods
into an instance you already have.

**Look inside an instance.** Tabs for Mods, Resource Packs, Shaders, Worlds
and Screenshots. Drop files in, remove what you do not want, open the folder.

**Settings per instance.** How much memory the game gets, which Java to use,
extra launch options. A slider turns red when you give the game too much or
too little.

**Two looks, two languages.** Pastel Overworld (light) and Pastel End (dark).
English and Spanish.

## Good to know

- **Online servers.** Servers that check for a Microsoft account will not let
  you in. Single player works, and so do servers set to "offline mode".
- **First time only.** The first Play for a version downloads the game (a few
  hundred MB). After that it starts right away.
- **The installers are not signed yet.** Windows and macOS show a warning the
  first time you open the launcher. The table below says how to get past it.
- Skins are not there yet.
