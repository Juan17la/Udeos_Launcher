Udeos Launcher is a small program to install and play Minecraft on Windows,
macOS and Linux. **You do not need a Microsoft account.** Pick a name, pick a
version, press Play.

This version also publishes everything that was meant for 1.2.1, which never
came out. If something breaks, please
[open an issue](https://github.com/Juan17la/Udeos_Launcher/issues) and say
what you did.

## What is new

- **Old versions open on Windows.** Minecraft 1.8.9 and other old versions
  could close right after pressing Play. They start now.
- **Update from the launcher works on Windows.** Windows asks for permission
  and the installer runs.
- **New look.** Dark is now diamond blue, Light is white, and **Custom** lets
  you pick your own colours. Each profile keeps its own.
- **Ask AI is a page.** Tell it what you want to play and it suggests mods,
  with the reason, ready to add.
- **Create in two clicks.** New instance and new server fit one screen with
  everything filled in. Press Create and play.
- **Activity button.** Downloads and launches show in a button on the top bar
  instead of floating over the page.
- **Servers from a modpack.** Make a server from a Modrinth modpack.
- **Join file for friends.** Save a small file from your server page. Your
  friends open it and get the same Minecraft version, loader and mods.
- **Datapacks.** Search them and add them to a world of your instance or server.
- **Smoother scrolling** on long lists, and a steadier top bar.
- **Fixes for servers.** A new server shows up right away, and one that is
  still starting can be stopped.

## Updating on Windows

If your launcher is 1.2.0 or older, **Update** can still fail once. Download
the Windows installer from the table below and run it. It installs over your
current launcher and keeps your instances, profiles and skins.

## Good to know

- **Online servers.** Servers that check for a Microsoft account will not let
  you in. Single player works, and so do servers set to "offline mode".
- **The installers are not signed yet.** Windows and macOS show a warning the
  first time you open the launcher. The table below says how to get past it.
