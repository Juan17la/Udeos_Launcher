Udeos Launcher is a small program to install and play Minecraft on Windows,
macOS and Linux. **You do not need a Microsoft account.** Pick a name, pick a
version, press Play.

If something breaks, please
[open an issue](https://github.com/Juan17la/Udeos_Launcher/issues) and say
what you did.

## What is new

- **One Add button.** On the Mods, Resource packs, Shaders and Datapacks tabs,
  Add now opens a small menu: search for it in Addons, or pick a file you
  already downloaded. The separate Browse files button is gone.

## Fixes

- **No more flicker on Linux.** The window no longer flashes when dialogs
  open or pages load.
- Dialogs, menus and loaders appear at once instead of fading in, so they do
  not blink the first time you open them.
- The Addons page stops blinking while it searches: it shows placeholder
  cards right away, keeps the old results while a new search runs, and Add
  buttons no longer flip to Added a moment later.

## Good to know

- **Online servers.** Servers that check for a Microsoft account will not let
  you in. Single player works, and so do servers set to "offline mode".
- **The installers are not signed yet.** Windows and macOS show a warning the
  first time you open the launcher. The table below says how to get past it.
