Udeos Launcher is a small program to install and play Minecraft on Windows,
macOS and Linux. **You do not need a Microsoft account.** Pick a name, pick a
version, press Play.

If something breaks, please
[open an issue](https://github.com/Juan17la/Udeos_Launcher/issues) and say
what you did.

## What is new

- **Servers are one click.** New servers let friends on any launcher join, and
  server cards show the whole address with Copy. Settings shows the few things
  most hosts change; the rest is under Advanced. The whitelist is off on new
  servers.
- **Starting a server shows real progress**, with about how long is left.
- **Servers cope with bad connections.** Stalled downloads retry and continue
  where they stopped, and a Fabric server that started once starts again
  without internet.
- **Lighter servers.** Smaller view and simulation distance by default and
  Java tuned for Minecraft.
- **A more consistent look.** Flat block-style buttons, one hopping grass
  block as the loader, neutral tags, and fewer solid blue buttons.
- **MIT license.** Anyone can use, change, share and sell Udeos Launcher as
  long as the license notice stays with it.

## Good to know

- **Online servers.** Servers that check for a Microsoft account will not let
  you in. Single player works, and so do servers set to "offline mode".
