Udeos Launcher is a small program to install and play Minecraft on Windows,
macOS and Linux. **You do not need a Microsoft account.** Pick a name, pick a
version, press Play.

If something breaks, please
[open an issue](https://github.com/Juan17la/Udeos_Launcher/issues) and say
what you did.

## What is new

- **A whole new look.** The launcher is now dark blue like a night sky, with
  rounder corners and real Minecraft items all over: next to page titles, in
  your stats and in empty lists. There is still a light theme and your own
  colours.
- **Pages on the left.** Instances, Servers, Skins and Addons now sit in a bar
  on the left, with a button to make something new right at the top.
- **Your last game comes first.** Instances are sorted by when you last played.
  The first one is a bigger card that shows when you played, for how long and
  what is in it, with a big Play button.
- **See it while it plays.** Pressing Play shows the download and start right
  on the button. While the game is open it says "Playing" with the minutes, and
  you can close a frozen game from there. When you finish, the launcher says GG.
- **Activity.** Downloads, installs, open games and running servers all show
  up in Activity at the bottom left, so you always know what is going on.
- **Removed a mod by mistake?** Press Undo. You have a few seconds.
- **Easier Addons.** Version, loader, sort and topics now live behind one
  Filters button, so the results come first. Topics are in Spanish too.
- **Long mod lists** show as a compact list with a filter box.
- **Calmer pages.** Nothing flickers when you switch pages or tabs anymore,
  and loading only shows when it really takes a moment.
- **Delete is in Settings now,** away from Play, and still asks first.
- **Memory is shown in GB**, the same way modpacks talk about it.

- **Online servers.** Servers that check for a Microsoft account will not let
  you in. Single player works, and so do servers set to "offline mode".
