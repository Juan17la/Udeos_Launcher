Udeos Launcher is a small program to install and play Minecraft on Windows,
macOS and Linux. **You do not need a Microsoft account.** Pick a name, pick a
version, press Play.

This is the fourth beta. It works, but it is still young: if something
breaks, please
[open an issue](https://github.com/Juan17la/Udeos_Launcher/issues) and say
what you did.

## What's new

**Each profile is its own.** Every profile now keeps its own skins,
language and theme, just like it already kept its own instances. Switch
profile and everything comes back the way that player left it. A new
profile starts with no skins. If you remove a profile, its skins move to
the one that stays. Skins you saved before this update go to the profile
that was wearing them.

**Play right after creating.** New Instance has a **Play as soon as it is
installed** box, ticked by default. Press Create and the game downloads
and opens without another click. Untick it if you only want to create the
instance.

**Drop skins anywhere.** On the Skins page you can drop a skin file
anywhere in the window, not just on the small box.

## Fixes

- **Old versions open on Windows again.** Versions 1.12 and older (like
  1.8.9) started but never showed their window. They open normally now.
- Dropping a file outside a drop zone does nothing now. Before, it could
  replace the launcher with the file.
- On an addon's page, the side panel with versions and your instances
  scrolls on its own, so a long list no longer drags the whole page.

## Still to come

- **Optimization.** Not done yet: some screens can feel slow, and the
  launcher can use more memory and CPU than it should. This is the next
  thing we are working on.

## Good to know

- **Online servers.** Servers that check for a Microsoft account will not let
  you in. Single player works, and so do servers set to "offline mode".
- **AI answers can be wrong.** The AI only picks from what Modrinth really
  has, and **Add** still checks that everything fits your instance, but its
  picks and reasons are suggestions.
- **The installers are not signed yet.** Windows and macOS show a warning the
