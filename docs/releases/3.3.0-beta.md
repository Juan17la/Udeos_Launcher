Udeos Launcher is a small program to install and play Minecraft on Windows,
macOS and Linux. **You do not need a Microsoft account.** Pick a name, pick a
version, press Play.

If something breaks, please
[open an issue](https://github.com/Juan17la/Udeos_Launcher/issues) and say
what you did.

## What is new

- **"Playing" only when you can play.** After you press Play, the card says
  "Opening…" until the game window is really on screen. Before, it said
  Playing while Java was still loading.
- **Crashes explain themselves.** If the game crashes or closes before it
  opens, the dialog tells you the likely reason (not enough memory, the wrong
  Java version, a missing or clashing mod, graphics drivers), what to do, and
  the lines from the game that show it. Copy them, open the crash report, or
  press Try again.
- **See what is downloading.** The Activity panel shows each mod's or
  modpack's icon, where it is being installed, how many files are done and
  which file is downloading. It now only lists downloads and installs.
- **Modpacks on the way.** While a modpack is being installed as a new
  instance, a grayed card with its progress waits in your library.

## Good to know

- **Online servers.** Servers that check for a Microsoft account will not let
  you in. Single player works, and so do servers set to "offline mode".
- **The installers are not signed yet.** Windows and macOS show a warning the
  first time you open the launcher. The table below says how to get past it.
